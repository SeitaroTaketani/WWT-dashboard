```bash
cd wastewater/dashboard
npm run dev          # 開発サーバー http://localhost:5174

npm run build && npx vite preview --port 8080   # 本番ビルドの確認 http://localhost:8080
```

スクリーンショット：`qa/shots/*.png` に最新版があります（PC 1440/1920、モバイル 390、各地域、パネル、散布図）。

## 4. 重要な発見（要確認）

1. **UN の TopoJSON は経度が約 11.31° ずれています。**
   - UN 地図は中央経線が約 11.31°E で、ファイル内の経度は「実際の経度 − 11.31」で保存されています。
   - `meta.json` などの実座標をそのまま使うと、ノード・ラベル・アークが約 11° 東にずれます。
   - 本ダッシュボードでは `CONFIG.geoLonOffset` で補正済みです。ヴェルデ岬とアガラス岬で実測して確認しました。
   - **SHC モニターも同じファイルを補正なしで使っているため、同じずれがある可能性が高いです**（ケニアのノードが海側にずれる、など）。確認をおすすめします。
2. 中国、ケニア、オーストラリアなどには JMP の「安全に管理された飲料水」の推計がなく、地表がグレーになります。
3. 関税が最も高いのはバハマ（38%）、バミューダ、ケイマンなど、財政収入のための関税を持つ島嶼国・地域です。壁には上限 20% をかけ、ラベルには実際の値を表示しています。

4. **地域別に見ると、パターンは一様ではありません**（MFN、需要の高い 1/4 と低い 1/4 の関税中央値）。
   - 世界 6.4% 対 1.2%（135 か国）、アフリカ 10.3% 対 5.2%（28）、アジア 5.3% 対 3.1%（36）
   - 欧州は 1.2% で同じ（EU の共通関税による）
   - **米州は逆で 0.7% 対 5.3%（17 か国と少数）**。KPI には「reversed」と表示し、隠さないようにしています。
   - オセアニアは両方のデータがそろう国が 3 か国しかないため、表示しません。

## 5. 私が判断したこと（変更可能。値はすべて `src/config.js` にあります）

| 項目 | 判断 | 理由 |
|---|---|---|
| 色 | 地表＝パープル、壁＝グレーから赤 | 仕様の「青緑→赤マゼンタ」の地表と「シアン→赤」の壁は、どちらも赤系で意味がぶつかるため。UNCTAD のパレットの範囲に収めた |
| 発光 | 使わない | UNCTAD スタイルを優先し、稜線の濃い線で代用 |
| ガイド | 5 / 10 / 20% | 実データの分布（中央値 3.6%）に合わせた。仕様の 10/20/30% では大半の国が最初の線に届かない |
| 貿易値 | 総額・方向あり、輸入国報告を優先 | 関税は総輸入額にかかるため、SHC の純額とは変えた |
| 技術グループ | ポンプ、ばっ気・空気処理、ろ過・浄化、処理プロセス機器、計測・制御 | 仮の分類。`scripts/process_wwt.py` の `GROUPS` で変更できる |
| 2D 切り替え | 真上ではなく 80° の「Top」 | 真上から見ると壁が線になり、関税の情報が消えるため |
| N→N の色 | グレー | SHC の方法論モーダルに合わせた |

## 7. 追加実装：A（二変量コロプレス）と D（推計関税負担額）

| 項目 | 内容 |
|---|---|
| **D：推計関税負担額** | 貿易路ごとに「貿易額 × 輸入国の HS 別関税率」を合計。欠けている HS の税率はその国の平均で補い、EU 域内は無税（関税同盟）として扱う |
| アーク | **太さ = 関税負担額（$）、色 = 実効関税率**（負担額 ÷ 貿易額。**分岐配色：世界平均の実効関税率（全 16 品目・MFN・2024 年で 2.46%。品目や MFN/AHS を変えると再計算）より低いと水色〜青、平均ちょうどでグレー、高いと赤、15% 以上は濃い赤**。ノードは中立色（輸出国は白、輸入国は濃いグレー）。白い縁取り付き）。「Arcs: Trade value」で太さを貿易額に、「Colour: N/S」で色を北南分類に戻せる。閾値も指標に合わせて自動調整 |
| KPI | 推計関税負担額（範囲内の合計）、そのうち**水不足が最も深刻な 1/4 の国が払っている額**、実効関税率（負担額 ÷ 輸入額）、#1 Duty payer |
| 国パネル・ツールチップ・CSV・散布図 | 負担額と輸入額に対する割合、HS 別の負担額。散布図の円の大きさ = 負担額 |
| **A：二変量コロプレス** | 「Map: Need × tariff」ボタンで切り替え。需要 3 段階 × 関税 3 段階の 9 色（紫 × 赤）。**最も濃いワイン色 = 需要が高く関税も高い**。真上からの 2D 表示で、壁は非表示（色に関税を含むため） |
| URL | `v=biv`（二変量）、`m=value`（アークを貿易額に）、`k=ns`（アークの色を北南分類に） |

**数値（2024 年・全 16 品目）**
- MFN：推計関税負担 $6.66B、そのうち水不足が最も深刻な 1/4 の輸入国 $871M

**注意点（方法論に明記済み）**
- EU 以外の特恵（FTA など）はモデル化していないため、MFN は上限の推計です。
- 公共事業や援助案件での免税、関税がなければ生じていたはずの輸入は考慮していません。

## 8. 散布図の刷新と描画の高速化

- **散布図**：右下に浮いたカードをやめ、「Need vs tariff」パネルとして**左側に固定**しました。1400px 以上では最初から開き、スマホでは下から出るシートになります。
  - 背景の 3×3 の区画と点の色を二変量マップと同じ 9 色にそろえたので、散布図がそのまま二変量マップの凡例になります。
  - 点の大きさ = 推計関税負担額。地域を絞り込むと、範囲外の点は地図と同じように薄くなります。
  - ホバーと選択は地図と双方向に連動し、点に国名も出ます。
  - 下に「**High need · high tariff**」の一覧（26 か国、負担額順）を置きました。クリックすると地図がその国へ移動し、国パネルが開きます。
- **描画の高速化**：GPU のない環境（ソフトウェア描画）を自動で見分け、流れる粒子を止めて、変化があったときだけ描き直すようにしました。GPU なしの環境で、年の切り替えは約 2.3 秒から約 0.3 秒に、フレームレートは 3fps から 24〜46fps になりました。GPU のある PC ではこれまでどおり粒子が流れます。

## 10. アーク表現の見直し（ブレインストーミングの結果）

- **アーク = 貿易（モノの流れ）**：太さは常に貿易額です。
- **前半**：素の輸出価格＝関税 0% の状態なので、税率の色の尺度で 0% にあたる青で描きます（ご提案どおり。尺度が一貫し、色の変化の大きさ＝関税の重さになります）。
- **全アーク共通の中間点**：輸入国の関税が上乗せされ、線が税率の色（世界平均より高いと赤、低いと青）に変わり、税率の分だけ太くなります。
  - 太くなる幅は、見やすくするため 4 倍に誇張しています（凡例と方法論に明記）。
  - 国境ではなく中間点にしたのは、小さな国でも変化が必ず見えるようにするためです（ご指摘どおり）。
  - アークにホバーすると、中間点に「+7.3% +$89K」のラベルが出ます。
- **関税負担額（ドル）**：アークではなく、輸入国の円と KPI で表示します（払われる場所に置く）。
- **左パネル**：「$100 の機器が国境を越えるといくらになるか」のはしご図を追加しました。
  - 例：エチオピア $111.5、中央アフリカ $110.6。比較として、水不足の少ない国の中央値 $101.2、全体の中央値 $102.5 を並べています。

## 11. アークの色が輸出国ごとに違う理由と、ツールチップの品目内訳

- アークの色＝その貿易路の実効関税率＝ Σ（品目ごとの貿易額 × 輸入国のその品目の税率）÷ 貿易額。輸入国が同じでも、**輸出国ごとに送る品目の構成が違う**ため色が変わります。
  - 例：カナダ → エチオピアは、浄水機械（842121、税率 30%）が 91% を占めるので 29.1%。中国は制御盤（5%）が中心なので 8.3%。
- アークのツールチップに**「What is shipped」**を追加しました。上位 3 品目のシェアと、輸入国のその品目の税率（税率の色つき）を表示します。欠けている税率を平均で補った品目には * を付けています。
- 「Importer's MFN tariff」は単純平均であることをラベルに明記し、実効税率と区別しました。
- 分かったこと：エチオピアは、水処理の中核機器（浄水・ろ過機械、流量計、圧力計）に 30% をかけています。これは「16 品目の平均 11.5%」には表れません。
